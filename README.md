## ✨ Features

- 🎨 **Modern UI/UX** - Clean and intuitive design with glassmorphism effects
- 📱 **Fully Responsive** - Seamless experience across all devices
- 🌙 **Dark Theme** - Eye-friendly dark color scheme
- ⚡ **Fast Performance** - Optimized with React and deployed on Vercel
- 📊 **Live Stats** - Real-time LeetCode and Codeforces statistics integration
- 🎯 **Interactive Elements** - Smooth animations and hover effects
- 🧭 **Easy Navigation** - Intuitive routing with React Router

---

## 🚀 Tech Stack

### Frontend
- **React.js** - Component-based UI library
- **Material-UI (MUI)** - Modern React component library
- **React Router** - Client-side routing
- **Lucide React** - Beautiful icon system

### Styling
- **Custom CSS** - Tailored animations and effects
- **MUI System** - Responsive design utilities
- **Glassmorphism** - Modern UI aesthetic

### APIs
- **LeetCode Stats API** - Fetch coding statistics
- **Codeforces API** - Display competitive programming data

### Deployment
- **Vercel** - Serverless deployment platform

## 🛠️ Installation & Setup

1. **Clone the repository**
   ```bash
   git clone https://github.com/fjiolla/My-Portfolio.git
   cd My-Portfolio
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```

4. **Build for production**
   ```bash
   npm run build
   ```
